# CS-340-ClientServer

## How do you write programs that are maintainable, readable, and adaptable?

I write programs by separating different responsibilities into their own functions or modules. The CRUD Python module was useful because it kept the database operations separate from the dashboard code. This made the project easier to read, test, and modify. It also made the CRUD module reusable, since the same database functions could be used by another Python application in the future.

## How do you approach a problem as a computer scientist?

I approach problems by breaking the requirements into smaller, manageable parts and testing each part before putting everything together. For this project, I first focused on the MongoDB database and CRUD operations before connecting them to the dashboard. This was different from some previous assignments because I had to consider the needs of an actual client and how the final application would be used. In future projects, I would use the same approach by identifying the client's requirements first, designing the database around those requirements, and testing each component independently.
